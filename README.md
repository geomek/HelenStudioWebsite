# Helen Studio Website

This is a professional website project for *Helen Studio, built using **TypeScript, **HTML, and **CSS*.

## 🛠️ Features
* Responsive design for mobile and desktop.
* Custom font integration.
* Optimized assets (WebP).

## 🚀 Getting Started
To run this project locally:
1. Clone the repository.
2. Install dependencies (if any) using npm install.
3. Run the development server with npm run dev.

## 📂 Project Structure
* /CustomFonts: Brand-specific typography.
* helenstudio.ts: Main logic and interactions.
